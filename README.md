## 🏗️ Microservices Architecture (Fitness App)

```
                    ┌─────────────────────────────────────────────┐
                    │           Spring Cloud Config Server         │
                    │        (Centralized Configuration)           │
                    └──────────────────┬──────────────────────────┘
                                       │
                    ┌──────────────────▼──────────────────────────┐
                    │           Netflix Eureka Server              │
                    │          (Service Discovery)                 │
                    └──────────────────┬──────────────────────────┘
                                       │
              ┌────────────────────────▼────────────────────────┐
              │              Spring Cloud Gateway                │
              │       (Routing · Load Balancing · Auth)          │
              └──────┬──────────────────────────────┬───────────┘
                     │                              │
          ┌──────────▼───────────┐      ┌──────────▼──────────────┐
          │    User Service      │      │   Activity Service       │
          │   (PostgreSQL)       │      │    (MongoDB)             │
          └──────────────────────┘      └────────────┬────────────┘
                                                     │  Apache Kafka
                                        ┌────────────▼────────────┐
                                        │      AI Service          │
                                        │  (Event Consumer)        │
                                        └─────────────────────────┘
```
